# Lorenz–63 无记忆条件生成模型：实验说明

本仓库是论文 *Capabilities and Limits of Memoryless Conditional Generative
Models for Coarse-Grained Dynamics*（撰写中）相关的计算实验，研究标量观测下
无记忆条件生成模型对边缘分布、相邻时刻联合分布及多步时间相关性的刻画能力。

## 研究对象与方法

Lorenz–63 系统参数为 $\sigma=10$、$\rho=28$、$\beta=8/3$，仅观测其
$x$ 坐标，采样间隔为 $\Delta=0.01$。模型以当前标量状态和独立标准高斯噪声
生成下一时刻状态，定义一阶 Markov 代理过程；真实标量观测过程并不预设为 Markov。

生成器是 $2\to96\to96\to1$ 的全连接网络，隐藏层采用 GELU，无残差连接。
状态输入在网络内部标准化，输出保持原始单位。每个坐标使用 1,500 个余弦特征，
目标函数为全部 $1500\times1500$ 个相邻状态交叉矩的均方差。

主实验执行 1,000 次 Adam 和 4,000 次 L-BFGS 更新。Adam 每次使用 100,000
个训练输入和每输入 50 个噪声样本；L-BFGS 使用固定的 586 个经验输入求积节点
及 128 个 Gauss–Hermite 噪声节点。优化更新次数与求积节点数是不同参数。

频率分布为 $\mathcal N(0,\gamma^{-2})$，其中
$\gamma=0.9954746006464024$。该数值由标准化训练输入的全部不同索引点对距离
中位数确定，但本实验的傅里叶特征在原始状态坐标上计算。NumPy 的
`scale=1/gamma` 指定标准差，与上述方差约定一致。

完整数学定义与优化设置见 [英文首页](../README.md) 和 [训练方法](TRAINING.md)。

## 数据与评价协议

训练文件包含去除初始过渡段后的 2,000,000 个观测，对应 1,999,999 个相邻对。
验证文件包含另一条轨迹的 100,000 个观测，已排除初始过渡段，并曾用于训练监测。
轨迹初值、积分容差和时间范围见 [数据说明](../data/README.md)。

- **边缘分布：** 三条自主生成轨迹各生成 1,100,000 点，去除前 100,000 点后，
  分别计算相对于训练参考的 Wasserstein-1 距离，再对三个距离取平均。
- **相邻联合分布：** 使用独立保存的 2,000,000 点连续生成轨迹，统计
  1,999,999 个相邻对。图中格点值为概率质量。
- **观测输入下的单步诊断：** 对 99,999 个验证输入各生成 32 个噪声样本。
  该协议不同于模型自由迭代的自主演化。
- **自相关：** 每条轨迹独立中心化、归一化后计算 ACF，再对模型曲线取平均。
  时间范围 0–0.1 包含 11 个离散滞后点；0–0.01 仅包含两个点。

[检查点敏感性分析](../results/checkpoint_scan/README.md) 比较了 4,000–24,000
次 L-BFGS 更新后的模型，每隔 1,000 次取一个检查点。该分析每条链保留
2,000,000 点，独立于主实验每条链保留 1,000,000 点的统计记录。

## 结果与解释

主实验三条自主轨迹的边缘 Wasserstein-1 距离平均为 0.09111676885。
一步滞后的自相关与参考较为接近，但模型的自相关在较长滞后下衰减明显偏慢。
这些结果体现了单步统计匹配与多步时间依赖之间的区别。

论文中精确条件核的边缘律和相邻联合律保留结论要求平稳初始化，不能直接作为
有限样本训练网络的精确性质。当前诊断不能将时间相关误差完全归因于记忆缺失，
因为单步学习误差及长期边缘分布偏移同样可能产生影响。有限轨迹不构成不变测度
存在性、唯一性或全局收缩条件的证明。

## 复现

在仓库根目录安装依赖并从保存结果重绘图形：

```bash
python -m pip install -r requirements.txt
python scripts/plot_results.py
```

完整 CPU 评价和 CUDA 训练分别为：

```bash
python scripts/evaluate.py --output outputs/evaluation
python scripts/train.py --device cuda --output outputs/training
```

每次运行使用新的输出目录。模型文件 `models/k1500_gh4000.pt` 对应 1,000 次
Adam 和 4,000 次 L-BFGS 更新，文件名沿用保存记录中的标识。软件环境、数值
一致性检查及其适用范围见 [数值复现说明](VERIFICATION.md)。

# K1500 / GH4000 精简版

这份目录是独立的新版本。原来的实验代码、模型、结果没有被覆盖。

主入口是 `scripts/train.py`。训练时没有逐轮进度播报，没有庞大的预检查、恢复训练或验证选模框架。它固定执行1000次Adam和4000次GH/L-BFGS，保存最终模型。

为便于阅读，网络、损失和积分分别放在 `code/` 下的小文件中；它们不是不同实验。配置只有一份 `configs/experiment.json`。

## 只看结果

打开首页 `README.md`，或直接打开 `results/figures/` 里的图片。保存的模型是 `models/k1500_gh4000.pt`。这些都是现有实验的K1500结果。

## 运行

在这个项目文件夹打开命令行，按README安装依赖，然后：

```text
python scripts/plot_results.py
python scripts/evaluate.py --steps 1000 --validation-points 1000 --output outputs/quick
```

第一条从已存结果重画图。第二条是短运行，确认代码能正常工作，它的短轨迹指标不能代替原论文式结果。

完整评估和重新训练分别为：

```text
python scripts/evaluate.py --output outputs/full_evaluation
python scripts/train.py --output outputs/retrained
```

重新训练需要CUDA版PyTorch和GPU，在原电脑上约需1–1.5小时，本次完整核对用了约88分钟。训练中保持安静是设计如此；不要因为没有显示轮数而重复启动。每次选一个新的输出目录。

## “结果一样”怎么判断

第一轮精简脚本已经从头完成1000次Adam和4000次GH训练：全部最终参数和标准化常数与原模型逐位相同，最大差异为0。三条完整评估轨迹也逐位相同。后续又去掉了文件指纹计算和模型输入模式开关，其数值对照范围单独记录在 [VERIFICATION.md](VERIFICATION.md)。

模型内部标准化、随机数顺序、浮点精度、分块大小和优化器历史都会影响结果，因此这些细节保留；进度文字和历史运行框架已去掉。

## 标准化、带宽和验证数据

模型只支持标准化输入：网络接收 `(x - mean) / std` 和标准高斯噪声，输出仍是原始物理单位的下一步状态。矩匹配中的傅里叶特征仍在原始状态坐标上计算，与已有实验一致。

数学上频率满足 `w ~ N(0, gamma**-2)`，第二个参数是方差。NumPy 的 `normal(loc=0, scale=1/gamma)` 中 `scale` 是标准差，所以平方没有遗漏。这里 `gamma=0.9954746006464024`，由标准化训练输入的全部不同索引点对的绝对距离中位数得到；原实验直接把这个数值作为原始坐标特征的带宽。

`validation_x.npy` 已经去除初始过渡段。它来自初值 `(1,1,1)` 的历史轨道：先丢弃10万点，再经过80万点历史训练段，随后取10万点作为验证集。时间步为0.01，验证时间区间是9000.00到9999.99。当前200万点训练集另由初值 `(2,3,4)` 的轨道生成。详见 [数据说明](../data/README.md)。
